# Weekly Update (2026-07-27)

## LeJEPA-Text — paired-view (cross-view JEPA) results

Ran the view-gap test: from-scratch JEPA on genuine semantic pairs —
docstring↔code (CodeSearchNet) and document↔summary (XSum) — 30k steps,
768d/12L, three arms per corpus, evaluated on frozen mean-pool MTEB **and**
cross-view retrieval (r@1, N=1000, chance = .001).

| Arm | code MTEB | summary MTEB | code r@1 | summary r@1 (clean test split) |
|---|---|---|---|---|
| pure (JEPA only) | .086 | .070 | .0005 | .002 |
| anchored (JEPA + MLM) | .338 | .387 | .118 | .281 |
| shuffled (pairs broken) | .344 | .382 | .116 | .269 |

- **A real view gap alone does not rescue from-scratch JEPA** — `pure` lands
  *below* the same-text chance ceiling (.164) on both corpora, at exact
  retrieval chance.
- **The pairing is not load-bearing:** anchored ≈ shuffled on 2 corpora × 2
  metrics; the MTEB delta even flips sign between corpora (±.006). The
  anchored arms' retrieval skill is MLM + lexical overlap, not learned
  correspondence (proven by pure-at-chance + shuffled≈real).
- Confirms the abstraction-gap thesis: LLM-JEPA/DLLM-JEPA gains must come from
  the pretrained backbone, not the paired data per se — we are the first to
  unconfound the two.

## Theory — floors proved, failure re-classified

- **Proved the two chance floors** with assumptions verified on our runs:
  per-token 2/P (predicted .0026, measured .0025) and pooled
  1/L + (1−1/L)ρ̄ — l_span's flatline at .125 = 1/8 exactly implies ρ̄ ≈ 0,
  l_glob .011 implies ρ̄ ≈ .003.
- **Linear two-view analysis: JEPA + target whitening reduces to CCA** — so
  the pairing signal *is* extractable by prediction in principle; the
  from-scratch failure is a **dynamics** failure (whitening gradient dominates
  ~25× before weak correlations amplify), not an information-theoretic one.
- Registered predictions P1–P4 (mask/THEORY.md) before the deciding runs,
  incl.: contrastive will extract the pairing where prediction couldn't.

## Reproduction / control apparatus built

- Paired trainer now has **7 arms**: pure / anchored / shuffled + `llmjepa`
  (λ=0 — faithful LLM-JEPA, rules out "SIGReg killed it") + `mlmonly`
  (batch-matched CE baseline) + `contrastive` / `con_shuffled` (in-batch
  InfoNCE — the non-JEPA positive control on the same pairs).
- **Cross-view retrieval eval** for any frozen checkpoint + HF baselines
  (BERT-base, MiniLM) on identical pairs, for calibration and a pretrained-
  encoder reference.
- **Part III plan** (ft/PLAN.md): CoT as the predictor's *action* —
  LeWorldModel's action-conditioned JEPA (LeCun/Balestriero 2026) ported to
  language finetuning; LLM-JEPA/DLLM-JEPA both dropped the action. CoT
  conditions the predictor only (never the token loss) → test-time inference
  without CoT. Staged Llama-1B → LLaDA-8B, A0–A5 ablation ladder.

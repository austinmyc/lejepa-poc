# Weekly Update (2026-07-27)

## Paired-view JEPA: the view gap alone does not rescue from-scratch training

Tested whether genuine cross-view pairs fix last week's null — docstring↔code
(CodeSearchNet) and document↔summary (XSum), from scratch, 30k steps, frozen
mean-pool MTEB + cross-view retrieval (N=1000, chance r@1 = .001):

| Arm | code MTEB | summary MTEB | code r@1 | summary r@1 (clean test split) |
|---|---|---|---|---|
| pure (JEPA only) | .086 | .070 | .0005 | .002 |
| anchored (JEPA + MLM) | .338 | .387 | .118 | .281 |
| shuffled (pairs broken) | .344 | .382 | .116 | .269 |

References: BERT-base .4825; Part-I MLM-only ctrl .4485 (batch 128, single-text
— not directly comparable; the batch-matched `mlmonly` runs next week).

- **Pairing is not load-bearing:** anchored ≈ shuffled on 2 corpora × 2 metrics
  (MTEB Δ ±.006, sign flips between corpora). The anchored arms' retrieval
  skill is MLM + lexical overlap (pure sits at exact chance).
- Scope: this establishes the *pairing-null*; "JEPA vs no-JEPA" awaits `mlmonly`.

## Theory + apparatus: the null is now explained and testable

- **Proved the two chance floors** (assumptions verified on our runs): per-token
  2/P — predicted .0026, measured .0025; pooled 1/L + (1−1/L)ρ̄ — explains
  l_span = .125 (=1/8, ρ̄≈0) and l_glob = .011 (ρ̄≈.003) exactly.
- **Linear analysis: JEPA + target whitening reduces to CCA** ⇒ the pairing
  *is* extractable by prediction in principle; the failure is a **dynamics**
  problem (whitening gradient dominates ~25× before weak correlations amplify),
  not information-theoretic. Conjecture: prediction's anti-collapse term fights
  its signal term; contrastive's are the same term — so negatives should
  succeed where prediction failed. **Predictions P1–P4 registered**
  (mask/THEORY.md) before the deciding runs.
- Apparatus now covers the full control grid: λ=0 faithful LLM-JEPA, batch-
  matched MLM-only, InfoNCE contrastive ± shuffled (the non-JEPA positive
  control), cross-view retrieval eval with BERT/MiniLM baselines.

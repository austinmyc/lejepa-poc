# Weekly Update (2026-07-27)

## Paired-view JEPA: the view gap alone does not rescue from-scratch training

Tested whether genuine cross-view pairs fix last week's null — docstring↔code
(CodeSearchNet) and document↔summary (XSum), from scratch, 30k steps, frozen
mean-pool MTEB + cross-view retrieval (N=1000, chance r@1 = .001):

| Arm | code MTEB | summary MTEB | code r@1 | summary r@1 (clean test split) |
|---|---|---|---|---|
| pure (JEPA only) | .086 | .070 | .0005 | .002 |
| anchored (JEPA + MLM) | .338 | .387 | .118 | .281 |
| shuffled (pairs broken) | .344 | .382 | .116 | .269 |

References: BERT-base .4825; Part-I MLM-only ctrl .4485 (batch 128, single-text
— not directly comparable; the batch-matched `mlmonly` runs next week).

- **Pairing is not load-bearing:** anchored ≈ shuffled on 2 corpora × 2 metrics
  (MTEB Δ ±.006, sign flips between corpora). The anchored arms' retrieval
  skill is MLM + lexical overlap (pure sits at exact chance).
- Scope: this establishes the *pairing-null*; "JEPA vs no-JEPA" awaits `mlmonly`.

## Why the JEPA loss looked fine but learned nothing (chance-level analysis)

- A predictor that learns **nothing** still gets a small loss in our setup: for
  768-dim normalized targets the "know-nothing" level is 2/768 = **.0026**, and
  our training loss sat at **.0025** the whole run. For pooled 8-token targets
  the know-nothing level is 1/8 = **.125** — observed exactly .125. So the
  latent losses were not "converging"; they were **flat at chance**. (Derived
  and verified in mask/THEORY.md.)
- **Why prediction fails but contrastive should work** (hypothesis, written
  down *before* the runs): a simplified linear version of our setup reduces to
  CCA, which provably *can* extract cross-view correlation — so the pair
  signal exists in principle. The failure is in training dynamics: from random
  init the predictable signal is ≈0, and the variance regularizer crushes it
  before it can grow. Contrastive learning escapes this because its
  collapse-prevention (in-batch negatives) IS its learning signal. Concrete
  prediction: InfoNCE on the same pairs will learn the correspondence where
  JEPA didn't.

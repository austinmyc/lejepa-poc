# Weekly Update (2026-08-03)

## Last week's prediction confirmed: contrastive extracts the pairing, prediction does not

Ran the contrastive positive control and the confound arms (8 new runs, same
pipeline/encoder/batch/steps as before — only the objective differs). Isolating
the pairing effect by comparing each mechanism against its **own shuffled-pairs**
control:

| mechanism | pairing effect (code) | pairing effect (summary) |
|---|---|---|
| JEPA (predictive) | **−.006** | **+.005** |
| Contrastive (InfoNCE) | **+.296** | **+.269** |

- The pairs **do** carry a large learnable signal — InfoNCE recovers ~.28 of it
  from scratch; predictive JEPA recovers none. The mechanism story predicted
  exactly this, and it could have come out the other way.
- Payoff: our JEPA null is now **attributable to the objective** — the apparatus
  detects a pairing effect ~50× larger when the mechanism can use it, so "maybe
  nothing works at your scale" is ruled out.

## Confounds closed

- **Faithful LLM-JEPA (no SIGReg) is still inert** — .3464 vs the no-JEPA
  baseline .3401. Rules out "your regularizer caused the null."
- **Ordering on both corpora: no-JEPA ≥ JEPA-without-SIGReg > JEPA-with-SIGReg**
  (summary .4298 / .4184 / .3868). Cross-view adds nothing; SIGReg costs
  ~.03–.04; the remaining gap to the Part-I baseline is pipeline (batch 96 +
  paired corpus), not the objective.
- All four predictions registered *before* these runs came out confirmed,
  including the one that could have falsified the mechanism story.

Scope: contrastive is not "the better pretraining objective" (it loses to plain
MLM on summary — it has no token supervision). The claim is strictly the
**pairing effect within each mechanism**, which the shuffled controls isolate.

## DLLM-JEPA: first runs launched

**Gate 1** — reproducing the published gain (LLaDA-8B GSM8K 42.61 → 61.33) — is
running now; the action arms only get compute if it passes. Two decisions worth
flagging:

- **Fitting an 8B model on our GPUs.** The paper full-finetunes on 8×A100. We
  use LoRA, and keep the EMA teacher as an EMA of the LoRA deltas only — since
  the base weights are frozen and shared between student and teacher, this is
  equivalent to a full EMA copy but costs megabytes instead of a second 16 GB
  model.
- **The reproduction and the CoT-action experiment need different generation
  targets** — the reproduction has the model generate its CoT (as in the paper),
  while the action experiment uses answer-only targets so that *no CoT is
  generated at test time* and the CoT enters only as the predictor's action.
  They therefore run as two separate stages, and the no-action answer-only arm
  (not the reproduction arm) is the correct reference for the CoT-action arm.
  Missing this would have confounded conditioning with target format.

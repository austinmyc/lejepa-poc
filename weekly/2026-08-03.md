# Weekly Update (2026-08-03)

## Main result: the paired signal is learnable from scratch — but not by prediction

Completed the 7-arm control grid on both paired corpora (14 runs, 30k steps,
768d/12L, from scratch). Every arm sees the same pairs, encoder, batch, and
steps — only the objective differs. Isolating the pairing effect by comparing
each mechanism against its own **shuffled-pairs** control:

| mechanism | pairing effect (code) | pairing effect (summary) |
|---|---|---|
| JEPA (predictive) | **−.006** | **+.005** |
| Contrastive (InfoNCE) | **+.296** | **+.269** |

- **The pairs carry a large learnable signal** — contrastive recovers ~.28 of
  it from scratch, with only 95 in-batch negatives.
- **Predictive JEPA recovers none of it** — real pairs are indistinguishable
  from scrambled pairs, on both corpora.
- This makes the JEPA null **attributable to the objective**, not to our scale
  or setup: the apparatus provably can detect a pairing effect (~50× larger)
  when the mechanism can use it.

Underlying MTEB numbers:

| Arm | code | summary |
|---|---|---|
| pure (JEPA only) | .0856 | .0704 |
| anchored (JEPA+SIGReg+MLM) | .3375 | .3868 |
| shuffled | .3435 | .3816 |
| llmjepa (JEPA+MLM, no SIGReg) | .3464 | .4184 |
| mlmonly (no JEPA) | .3401 | .4298 |
| contrastive | .3686 | .3767 |
| con_shuffled | .0723 | .1073 |

Scope: contrastive is not "the better pretraining objective" (it loses to plain
MLM on summary — it has no token supervision). The claim is strictly about the
**pairing effect within each mechanism**, which the shuffled controls isolate.

## Confounds closed

- **LLM-JEPA replicated faithfully (no SIGReg): still inert** — .3464 vs the
  no-JEPA baseline .3401. Rules out "your regularizer caused the null".
- **Ordering on both corpora: no-JEPA ≥ JEPA-without-SIGReg > JEPA-with-SIGReg**
  (summary .4298 / .4184 / .3868). Cross-view adds nothing; SIGReg costs
  ~.03–.04; the remaining gap to the Part-I baseline (.4485) is pipeline
  (batch 96 + paired corpus), not the objective.
- All four predictions registered *before* these runs (mask/THEORY.md) came out
  confirmed, including the one that could have falsified the mechanism story.

# Weekly Update (2026-08-03)

## Contrastive learning finds the pairing; JEPA finds none

Ran the contrastive control and the two confound arms (8 runs; same encoder,
data, batch and steps as last week — only the training objective differs). For
each objective, comparing real pairs against its own shuffled-pairs control:

| objective | effect of real pairs (code) | effect of real pairs (summary) |
|---|---|---|
| JEPA (prediction) | **−.006** | **+.005** |
| Contrastive (InfoNCE) | **+.296** | **+.269** |

- **The pairs do carry a strong signal — contrastive finds it, JEPA finds none.**
  This is what we predicted last week, and it could have come out otherwise.
- It also shows our JEPA result is about the objective, not about our small
  scale: the same setup finds a large pairing effect when the objective can use
  one.

New arms (MTEB mean; arms already reported last week are omitted):

| Arm | code | summary |
|---|---|---|
| contrastive | .3686 | .3767 |
| con_shuffled (pairs broken) | .0723 | .1073 |
| llmjepa (JEPA + MLM, no SIGReg) | .3464 | .4184 |
| mlmonly (no JEPA) | .3401 | .4298 |

Scope: contrastive is not simply the better pretraining objective — it loses to
plain MLM on summary, since it has no token supervision. The claim is only about
the effect of the pairing within each objective, which the shuffled controls
isolate.

## The two confounds are closed

- **LLM-JEPA without SIGReg still adds nothing** — .3464 vs the no-JEPA baseline
  .3401. So the null is not caused by our regularizer.
- **On both corpora: no-JEPA ≥ JEPA-without-SIGReg > JEPA-with-SIGReg**
  (summary .4298 / .4184 / .3868). The cross-view term adds nothing, SIGReg
  costs about .03–.04, and the rest of the gap to the Part-I baseline is the
  smaller batch and different corpus — not the objective.

## DLLM-JEPA: first runs launched

Gate 1 — reproducing the published gain (LLaDA-8B GSM8K 42.61 → 61.33) — is
running now. The action arms only get compute if it passes. Two decisions worth
noting:

- **Fitting an 8B model on our GPUs.** The paper fully finetunes on 8×A100. We
  use LoRA, and keep the EMA teacher as an EMA of the LoRA weights only. Because
  the base model is frozen and shared, this is equivalent to a full EMA copy but
  costs megabytes instead of a second 16 GB model.
- **The reproduction and the CoT experiment need different training targets.**
  In the reproduction the model generates its own reasoning, as in the paper. In
  the CoT experiment the target is the answer only, so no reasoning is generated
  at test time and the CoT is used only to condition the predictor. They are
  therefore run as two separate stages, and the answer-only arm without CoT (not
  the reproduction arm) is the right comparison for the CoT arm.
